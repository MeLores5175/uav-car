# 任务一单路舵机集成说明

- `uav_udp_gateway.py`：接受 `SERVO:LOCK/RELEASE`，只在未解锁且 `WAIT_START` 时转发。
- `air_ground_mission_fsm.py`：正式投放动作发送 `A90`。
- `drop_actuator_serial.py`：唯一串口拥有者，写入 `A30/A90` 并发布 ACK。
- `air_ground_mission.yaml`：增加锁止、释放和手动 ACK 超时参数。
- `d26_real_flight_fake_car_task1_stage1_base.launch`：由模拟 ACK 改为真实串口节点。
- `esp32/`：包含上电自动 A30 的 ESP32-C3 固件。
