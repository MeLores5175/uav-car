# 本版变更：右转入圆 + 出发点后移30 cm

## 1. 入圆方向

参考路径本来就是从第一段直线向右进入第一个半圆。

上一版本实车却向左，说明逻辑左右轮映射与物理底盘相反。
本版改为：

- 逻辑左轮：STEP19 / DIR21 / EN18，DIR=LOW 前进
- 逻辑右轮：STEP26 / DIR27 / EN25，DIR=HIGH 前进

独立LEDC定时器修复保持不变：

- 左轮通道0，初始997 Hz
- 右轮通道2，初始1009 Hz

## 2. 起点后移30 cm

实车摆放方式：

- 车头压在出发线上
- 车体/平台中心在出发线后方30 cm

因此：

- 初始中心到第一次入圆点：30 + 150 = 180 cm
- 对侧直线：仍为150 cm
- 半圆半径：仍为75 cm

不能简单把全局直线长度都改成180 cm，否则上下两个半圆的位置都会被改错。

## 3. 一圈终点

第二个半圆结束时，中心停在原出发线上。
由于初始中心位于线后30 cm，所以最终位置会比初始中心前进30 cm。
这是保持跑道两个半圆切点不变的自然结果。

## 4. 测试观察

第一段：

- segment=1
- 距离约180 cm后进入第一个半圆

第一个半圆：

- segment=2
- 应向右偏转
- 右转时逻辑左轮频率应高于逻辑右轮频率

串口应看到类似：

[MOTION] segment=2 ... left=21.xxcm/s(34xxHz) right=8.xxcm/s(13xxHz)
