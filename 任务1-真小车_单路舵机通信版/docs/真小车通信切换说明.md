# 任务一从假小车切换到真实 ESP32 小车

## 启动文件

正式真车通信使用：

```bash
roslaunch d26_air_ground_uav d26_real_flight_real_car_task1.launch
```

原来的 `d26_real_flight_fake_car_task1_stage1_base.launch` 保留，只用于虚拟小车测试。

## 当前联调地址

| 设备 | IP | 监听端口 |
|---|---:|---:|
| 地面站 | 192.168.77.104（可 DHCP，ESP32 会学习实际来源） | 8889 |
| 无人机 | 192.168.77.103 | 8888 |
| ESP32 小车 | 192.168.77.102 | 8890 |

必须同步检查：

1. ESP32 `mission_config.cpp`；
2. 本包 `launch/d26_real_flight_real_car_task1.launch` 的 `car_ip`；
3. 地面站设置页中的 UAV IP 和 CAR IP。

## 正式启动时序

```text
GS  -> UAV  CMD:<id>:BOOT:T1
GS  -> CAR  CMD:<id>:MODE:T1
GS  -> CAR  CMD:<id>:START:R001
CAR -> UAV  CMD:<id>:START:R001:T1   （同一命令号超时重发）
UAV -> CAR  ACK:<id>:START:OK:R001
CAR -> UAV  TEL:CAR:{...}             （20 Hz）
CAR -> GS   TEL:CAR:{...}             （20 Hz）
```

## TEL:CAR 必需字段

真实小车程序已补齐：

- `segment`：只发送 `AB/BC/CD/DA/UNKNOWN`；
- `path_s_cm`：从 A 点开始累计的路径里程；
- `line_detected`；
- `x_cm/y_cm/speed_cm_s/yaw_deg`；
- `run/task/state/error`。

## 重要限制

当前 ESP32 工程的位置来自步进电机运动模型/轮式里程计，不是外部定位真值；`line_detected` 暂时表示驱动链路正常。接入真正巡线传感器后，应把它替换为传感器检测结果。

本 ROS 包没有真实平台视觉节点。真车遥测能让无人机截获和伴飞，但 YAML 中 `mission.drop.vision_required: true`，所以进入投放下降前仍必须有节点发布：

```text
/uav/platform_vision
```

否则 FSM 会因视觉无效暂停下降或退出投放阶段。
