# 实体按键通信修正说明

## 正式流程

1. 地面站“准备所选任务”同时发送 UAV `BOOT:T1/T2` 与 CAR `MODE:T1/T2`。
2. 小车回复 `ACK:...:MODE:OK` 和 `EVT:CAR_READY:T1/T2`，但不运动。
3. 队员按 GPIO32 实体按键。
4. 小车发送 `EVT:CAR_COUNTDOWN:<run>:<task>:10`，保持静止 10 秒。
5. 倒计时结束后，小车开始运动，同时向无人机发送 `CMD:<id>:START:<run>:<task>`。
6. 地面站从 `EVT:MISSION_START` 开始显示任务运行。

网页中的 START 已禁用，只作为状态和倒计时显示，不会发送远程启动命令。

## gateway 修正

- `TEL:CAR` 含 `vx_cm_s/vy_cm_s` 时直接使用平台中心速度分量。
- 旧小车没有速度分量时才退回 `speed_cm_s + yaw_deg`。
- `COUNTDOWN`、`READY`、`IDLE` 均明确判定为 `running=false`。
